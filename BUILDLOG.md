## 2026-09-24 22:05 — Phase 3 done: workflow, agents, Functions
- Workflow case-lifecycle v1 (5 stages + closed, 4 automated effects, human actions for Director and Investigator). `sanity-workflows deploy --check` accepted the definition on the first attempt; deployed to the same dataset as the content. Definition sharing with Sanity is ON by default (definition only, no content).
- Handlers (workflow/handlers): agent-triage, agent-crossref, mirror-review/investigation, file-verdict. Routing is deterministic code (workflow/lib/routing.ts), shared with the seed builder so the two cannot drift. The model proposes a score and flags; code decides the route. spirit category always gets faith-sensitive added in code; a faith-sensitive case can never be routed to auto-debunk and the file-verdict handler refuses an agent DEBUNKED stamp on one.
- Every handler is idempotent (effectKey-guarded log entries, forward-only status mirror with revision checks, createIfNotExists for red strings, credibility recomputed from all closed cases). Instance ids are deterministic (prod.wf-instance.<caseId>), so starting a case twice resumes instead of duplicating.
- scripts/seed-workflows.ts drove all 30 seeded cases through the real engine with the same actions a person fires and verified the histogram: 8 classified, 9 debunked, 4 inconclusive, 5 investigation, 4 review. It matched the plan exactly. Witness credibility recomputed correctly (two classified of two closed = 75).

## 2026-09-24 22:50 — Phase 4 code complete: public site (not yet viewed in a browser)
- Next.js 16.3 + Tailwind v4 + next-sanity 13.3, App Router, all pages server-rendered. Routes: / , /cases (map + list, URL-synced filters), /cases/[caseNumber] (dossier), /report (4-step form), /report/filed/[caseNumber] (live tracker), /desk (public Director's Desk), /about, plus /api/pulse, /api/cases/[n]/status, /api/geo/search|reverse, sitemap, robots, OG images. `next build` passes.
- Design: "declassified dossier" tokens (paper/ink/stamp/red string) in globals.css, light + "night shift" dark, Source Serif 4 / IBM Plex Sans / IBM Plex Mono, SVG displacement filter for the ink-edge on stamps, reduced-motion and forced-colors handled.
- Decision: did NOT use next-sanity's defineLive (it couples to Next.js caching modes and adds risk). "Live" is a 7 s poll of /api/pulse that calls router.refresh() when any case changes, paused while the tab is hidden. Simpler, testable, good enough.
- Decision: no next/image (its loader prop cannot cross the server/client boundary); plain img with Sanity CDN srcset and LQIP backgrounds, width/height set to avoid layout shift.
- Safeguards in the report action: idempotent case id from a client UUID (double-click = one case), honeypot + 4 s minimum fill time answering with a generic error, per-caller hourly limit (in-memory: per instance, honestly not global; the hard cap on cost is the daily AI budget), IPs are salted-hashed and never stored, photos compressed in the browser (drops EXIF GPS, fits hosting body limits), case number from an atomic counter, workflow start failure keeps the case and logs it for wf:recover.
- Nearest-region assignment: a report filed within 200 km of a known region inherits it, so a report near Area 51 gets the restricted banner.
- Not yet verified by eye or by running: everything visual. That is the Phase 8 pass (the plan's one-test rule).

(5) stamp unreadable over a dark photo: added a solid variant. (6) cramped list rows and 6 px horizontal overflow on phones. (7) red-string graph tiny with 2 links: redrew. (8) form heading drew a focus ring on load. (9) skip link showed after client navigation: :focus -> :focus-visible.
**Calibration (the honest AI part):** first pass scored a credible, evidence-backed sighting 68, just under the 70 investigate bar, so it needed a person. Added a scoring guide to the prompt ("submitted photo, footprint or sound counts as physical evidence"; "vague is not false, score 20-49") and redeployed the Function: the same report then scored high enough to open an investigation and the Cross-Referencer proposed 3 real related files.
